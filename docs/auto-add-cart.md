# 自动加车（Chrome）

Apple 购物袋依赖浏览器会话。桌面程序不能只靠自己的网络请求把商品放进你正在使用的浏览器购物袋，所以此功能由配套 Chrome 扩展在 Apple 官方网页中执行。

1. 在桌面应用的「运行设置」中点击「打开扩展目录」。源码运行时也可以直接使用仓库的 `browser-extension/` 目录。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启「开发者模式」，点击「加载已解压的扩展程序」，选择刚才的目录（内有 `manifest.json`）。应用升级后如扩展未生效，在此页点击扩展的「重新加载」。
3. 将 Chrome 设为默认浏览器。在桌面应用中开启「有货时自动加车」，然后开始监控。

确认有货后，每次监控会话只打开首个命中目标的商品页。扩展在这个 Apple 页面中调用站点自己的加车功能；成功后自动进入同一浏览器会话的购物袋，点击 Apple 官方结账按钮并选择访客结账。失败时会在页面显示原因，你可以在那里手动操作。其他命中目标仍会发提醒，但不会连续添加多台设备。暂停再开始监控会重新启用一次加车机会。

扩展会带上监控目标的门店编号，在 Apple 结账页尝试选中同一家门店，然后尝试继续填写资料并选择支付宝。若 Apple 页面没有显示该门店或没有可识别的控件，扩展会停下并提示手动完成。请核对型号、数量、取货门店与价格。Apple 的隐私同意书由你自行阅读处理；最终确认订单和支付宝付款由你本人操作。加入购物袋不锁定库存；Apple 页面或反自动化机制变化时，自动步骤可能失败。

## 自动填充结账资料

点击 Chrome 工具栏的 Apple Pickup Watcher 扩展图标，再点击「打开结账资料设置」。可分别保存**到店取货联系人**和**配送收货资料**。此功能与自动加车开关相互独立；只要扩展已启用且在设置页勾选「在 Apple 结账页自动填充」，进入 Apple 结账页就会尝试填入资料。

资料使用 Chrome 扩展的本地存储，留在当前 Chrome 用户配置文件内，不写入桌面应用配置、网址或 Git 仓库，也不会通过扩展发往 Discord。扩展只填用途能够识别的空白文本字段，不覆盖已经输入的内容，不填账单、付款卡或发票资料，也不自动处理无法确认的下拉项。能识别且资料完整时会尝试点击非下单的「继续」按钮；未填上的字段请手动完成，并在下单前核对所有资料。请勿在共用的 Chrome 用户配置文件中保存私人资料。

## 支付宝链接显示与 Discord 推送

在桌面应用点「复制扩展连接码」，将连接码粘贴到 Chrome 扩展的「结账资料设置」并保存。桌面应用必须保持运行，扩展才能通过本机回环地址把链接送达应用。连接码只保存在应用配置目录和当前 Chrome 用户配置文件中；「删除资料和连接码」会清除扩展内的副本。

Apple 中国区会在你点击最终「现在下订单」后跳转支付宝。扩展仅在本次自动加车产生的结账标签页中捕获 `*.alipay.com` 页面；若页面暴露 `qr.alipay.com` 二维码目标链接，应用会显示该链接；否则显示支付宝收银台页面地址，并明确标注类型。链接也会发送到设置中已有的 Discord webhook。链接可能过期，付款前请核对商家和金额。扩展不会读取付款密码，也不会代你付款。
