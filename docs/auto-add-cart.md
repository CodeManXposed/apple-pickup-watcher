# 独立浏览器自动加车

Apple 购物袋依赖浏览器会话。自动购买任务使用独立的 Chrome for Testing 配置文件，由配套扩展在 Apple 官方网页中执行。它与日常 Chrome 的购物袋、登录状态和扩展资料分开。

1. 在桌面应用的「运行设置」中点击「准备独立浏览器」。首次操作会从 Google 官方 Chrome for Testing 下载地址安装当前稳定版到应用的本地数据目录，不改动日常 Chrome。下载完成后再继续。
2. 点击「打开独立浏览器」。应用会用专用配置文件启动 Chrome for Testing，并加载随应用打包的扩展。在该浏览器的扩展图标中打开「结账资料设置」，保存取货和配送资料。若扩展未出现，可在 `chrome://extensions` 检查加载状态。
3. 在桌面应用中点击「复制扩展连接码」，将连接码保存到**独立浏览器中的扩展**，以便回传支付宝链接。
4. 开启「有货时在独立浏览器自动加车」，然后开始监控。

确认有货后，每次监控会话只在独立浏览器中打开首个命中目标的商品页。扩展核对商品 SKU，在 Apple 官方页面选择“不折抵换购”和“不加 AppleCare+”（如页面要求），点击官方“添加到购物袋”按钮；确认购物袋中仅有一件该 SKU 后，点击 Apple 官方结账按钮并选择访客结账。购物袋中有其他商品或数量不是 1 时会停下，供你手动处理。失败时会在页面显示原因。其他命中目标仍会发提醒，但不会连续添加多台设备。暂停再开始监控会重新启用一次加车机会。

桌面应用的「自动结账进度」会显示当前目标从打开商品页、进入购物袋、访客结账、填写资料到等待提交订单的阶段。Apple 加车后若直接返回错误页面，扩展会停止并把失败立即回传桌面应用；实测 Apple 对官方加车请求可能返回 HTTP 541，即使商品配置页正常打开也无法加车。商品页打开后 90 秒内仍未确认加入购物袋，也会标记任务失败并在日志提示检查 Apple 页面。其他阶段若页面卡住或桥接断开，进度会停在最后收到的阶段；请查看浏览器页面上的提示。新的监控会话开始时，旧支付宝链接仍标记为「最近收到的」，不要把它当作新订单链接。

扩展会带上监控目标的门店编号和目录中的地区资料，在 Apple 结账页选择到店取货、对应地区与同一家门店，并尝试选择最早可用的取货日期和签到时段，再填写资料并选择支付宝。若 Apple 页面没有显示该门店、地区或时间控件无法识别，扩展会停下并提示手动完成。请核对型号、数量、取货门店、日期与价格。Apple 的隐私同意书由你自行阅读处理。加入购物袋不锁定库存；Apple 页面或反自动化机制变化时，自动步骤可能失败。

自动继续取货或配送资料页前，扩展会等待已启用的资料填充，并检查可见的必填项；资料缺失时会提示在 Apple 页面补全。
Apple 中国大陆取货页可能要求填写身份证件号码后四位并验证联系人手机号码。这两步须由你在 Apple 页面完成；扩展检测到“验证”按钮时会等待，不会代填证件信息或短信验证码。
遇到隐私同意书、手机验证或未完成的必填资料时，桌面应用会显示等待操作的阶段并发系统提醒；完成后扩展继续尝试进入付款方式。

## 自动填充结账资料

点击**独立浏览器**工具栏的 Apple Pickup Watcher 扩展图标，再点击「打开结账资料设置」。可分别保存**到店取货联系人**和**配送收货资料**。此功能与自动加车开关相互独立；只要扩展已启用且在设置页勾选「在 Apple 结账页自动填充」，进入 Apple 结账页就会尝试填入资料。

资料使用扩展的本地存储，留在独立浏览器配置文件内，不写入桌面应用配置、网址或 Git 仓库，也不会通过扩展发往 Discord。扩展只填用途能够识别的空白字段；原生下拉框只有在保存值与唯一选项精确匹配时才选择。不覆盖已经输入的内容，不填账单、付款卡或发票资料。资料完整时会尝试点击非下单的「继续」按钮；未填上的字段请手动完成，并在下单前核对所有资料。

## 单笔金额上限与自动提交订单

扩展设置页的「自动提交订单」默认关闭。启用时须填写取货人姓名、电话、邮箱、有效桌面连接码，以及人民币整数的单笔金额上限。只有本扩展自动加入的单件商品，且结账流程确认了监控门店和支付宝，才尝试读取 Apple 确认页的唯一订单总额。总额无法唯一识别、超过上限或无法确认门店及付款方式时会停下，供你手动核对。自动点击 Apple 最终下单按钮会生成待付款订单；支付宝付款仍由你本人完成。

## 支付宝链接显示与 Discord 推送

在桌面应用点「复制扩展连接码」，将连接码粘贴到独立浏览器扩展的「结账资料设置」并保存。桌面应用必须保持运行，扩展才能通过本机回环地址把链接送达应用。连接码只保存在应用配置目录和独立浏览器配置文件中；「删除资料和连接码」会清除扩展内的副本。

保存资料后，扩展设置页会检查连接码与桌面应用的本机桥接。请确认页面显示「已连接桌面应用」；若显示连接码不匹配或无法连接，请先修复再开始监控。

Apple 中国区会在提交最终「现在下订单」后跳转支付宝。扩展仅在本次自动加车产生的结账标签页中捕获 `*.alipay.com` 页面；若页面暴露 `qr.alipay.com` 二维码目标链接，应用会显示该链接；否则显示支付宝收银台页面地址，并明确标注类型。链接也会发送到设置中已有的 Discord webhook。链接可能过期，付款前请核对商家和金额。扩展不会读取付款密码，也不会代你付款。
