# 自动加车（Chrome）

Apple 购物袋依赖浏览器会话。桌面程序不能只靠自己的网络请求把商品放进你正在使用的浏览器购物袋，所以此功能由配套 Chrome 扩展在 Apple 官方网页中执行。

1. 在桌面应用的「运行设置」中点击「打开扩展目录」。源码运行时也可以直接使用仓库的 `browser-extension/` 目录。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启「开发者模式」，点击「加载已解压的扩展程序」，选择刚才的目录（内有 `manifest.json`）。应用升级后如扩展未生效，在此页点击扩展的「重新加载」。
3. 将 Chrome 设为默认浏览器。在桌面应用中开启「有货时自动加车」，然后开始监控。

确认有货后，每次监控会话只打开首个命中目标的商品页。扩展在这个 Apple 页面中调用站点自己的加车功能；成功后自动跳到同一浏览器会话的购物袋。失败时会在商品页显示原因，你可以在那里手动操作。其他命中目标仍会发提醒，但不会连续添加多台设备。暂停再开始监控会重新启用一次加车机会。

自动加车只选择零件号，不会替你选择取货门店。进入购物袋后，请核对型号、数量和门店可用性，再自行结账和付款。加入购物袋不锁定库存；Apple 的网页接口或反自动化机制变化时，这一步可能失败。

## 自动填充结账资料

点击 Chrome 工具栏的 Apple Pickup Watcher 扩展图标，再点击「打开结账资料设置」。可分别保存**到店取货联系人**和**配送收货资料**。此功能与自动加车开关相互独立；只要扩展已启用且在设置页勾选「在 Apple 结账页自动填充」，进入 Apple 结账页就会尝试填入资料。

资料使用 Chrome 扩展的本地存储，留在当前 Chrome 用户配置文件内，不写入桌面应用配置、网址或 Git 仓库，也不会通过扩展发往其他网站。扩展只填用途能够识别的空白文本字段，不覆盖已经输入的内容，不填账单、付款卡或发票资料，不选择下拉项，也不代替你点击下一步或提交订单。Apple 结账页的字段和流程会变动；未填上的字段请手动完成，并在下单前核对所有资料。请勿在共用的 Chrome 用户配置文件中保存私人资料。
